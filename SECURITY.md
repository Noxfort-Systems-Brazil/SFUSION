# Security Policy

## Supported Versions

Currently, SFUSION Mapper is in active development. Only the latest `main` branch is officially supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

**CRITICAL:** SFusion Mapper processes urban sensor feeds and microscopic road network definitions that directly inform downstream simulation and autonomous traffic orchestration systems (such as CARINA and SYNAPSE). Vulnerabilities in data ingestion or neuro-symbolic execution could potentially lead to malformed simulation artifacts or corrupted infrastructure mappings.

**DO NOT** disclose vulnerabilities publicly on GitHub Issues.

If you discover a vulnerability, please report it immediately by emailing:
**security@noxfort.com** *(Placeholder for Noxfort Systems Security Team)*.

We will acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress. If a fix is deployed, you will be publicly credited in our release notes (unless you prefer to remain anonymous).
