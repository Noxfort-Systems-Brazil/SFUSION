## 1. Порядок работы

1. **Открыть карту**: загрузить файл сети SUMO нажатием кнопки **Открыть карту** (`Ctrl+M`).
2. **Добавить источник**: выбрать каталог с данными телеметрии.
3. **Выполнить привязку**: нажать **Связать** и выбрать дорогу на карте (встречные направления связываются автоматически) или указать режим Global.
4. **Проверить схему**: просмотреть сопоставленные поля в правой панели и при необходимости задать пользовательское название улицы.
5. **Сформировать датасет**: нажать кнопку **Сформировать датасет** для генерации файла `.parquet`.
6. **Сохранить проект**: сохранить параметры сессии в файл `.sfm.json`.
