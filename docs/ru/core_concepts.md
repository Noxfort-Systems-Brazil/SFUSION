# 📖 Базовые концепции и теоретические основы

**SFusion Mapper** является ключевым инструментом инженерии данных «нулевого дня» (Day Zero) в составе программной экосистемы **SFusion ETL**. Его назначение — преобразование разрозненных данных дорожных датчиков в калиброванные кинематические массивы для микромоделирования в SUMO.

⬅️ [Главный Хаб](README.md) | 🏛️ [Архитектура](architecture.md) | 🔄 [Рабочий процесс](system_workflow.md)

---

## 1. Парадигма «нулевого дня» (Day Zero)

Классический подход к обработке данных датчиков требует ручного написания скриптов и регулярных выражений под каждый формат. Любое изменение протокола поставщиком выводит конвейер из строя.

**SFusion Mapper решает эту проблему**:
* Предоставляет визуальную рабочую среду подготовки («День Ноль»).
* Оператор загружает топологию сети и интерактивно подключает папки данных.
* Локальный ИИ (*Phi-4-mini*) автоматически определяет смысл колонок, проверяет их по законам кинематики и формирует высокоэффективный датасет в **Apache Parquet**.

## 2. Графовая топология и пространственная привязка

Телеметрия не имеет ценности без точной географической привязки:
* **Узлы (`MapNode`)**: перекрестки и развязки с координатами $(x, y)$.
* **Ребра (`MapEdge`)**: направленные участки дорог с полилиниями геометрии (`shape`).
* **Интеллектуальное спаривание полос**: автоматическое распознавание встречных направлений (`edge_123` и `-edge_123`) для одновременного назначения данных.
* **Локальная и глобальная привязка**:
  * **Глобальная**: параметры, общие для всего города (погода, общий скоростной режим).
  * **Локальная**: привязка к конкретному участку дороги или перекрестку (камера, индуктивная петля).

---

## 3. Нейро-символическое определение схем

Датчики разных производителей называют поля по-разному (`speed`, `current_speed`, `spd_kmh`):
* **Нейросетевой компонент**: локальная модель SLM анализирует текстовые заголовки и выявляет семантику.
* **Символический компонент**: резолвер (`NeuroSymbolicResolver`) сопоставляет гипотезы с физическими законами движения и заполняет типизированный контракт `KinematicMap`.

---

## 4. Векторная кинематическая нормализация

Для симуляторов требуются стандартные величины Международной системы единиц (СИ / SUMO):
$$\text{Скорость } (v) \in \text{км/ч}, \quad \text{Интенсивность } (q) \in \text{авт/ч}, \quad \text{Плотность } (k) \in \text{авт/км}$$

Движок `MathEngine` компилирует схему в **абстрактное синтаксическое дерево (AST)** выражений **Polars** (`pl.Expr`), исполняемое параллельно с SIMD-ускорением.
