## 1. 业务阶段划分

1. **路网拓扑摄取**：读取 SUMO XML 文件（`.net.xml` 或 `.net.xml.gz`），在内存中建立节点与路段图结构并在画布上矢量绘制。
2. **感知数据源扫描**：选取传感器文件夹，系统递归解析并标记文件类型。
3. **空间关联与智能推断**：将传感器关联至道路（局部）或全城（全局），触发 Phi-4-mini 完成参数解析与物理验证。
4. **ETL 暂存与矢量计算**：多线程并行抽取原始记录写入临时 SQLite WAL 库，同时并行求解 Polars 物理 AST 表达式。
5. **金标 Parquet 导出与销毁**：合并空间坐标与 UTC 绝对时间戳，生成 Snappy 列式文件并清除临时文件。
